# 🛒 SmartCart – Flask E-Commerce Web Application

SmartCart is a full-stack e-commerce web application developed using Flask.  
It provides a modern online shopping experience with user authentication, cart management, secure checkout, admin product management, invoice generation, and responsive UI design.

# 🚀 FEATURES

## 👤 USER FEATURES

- User Registration & Login
- Secure Password Hashing
- Profile Update with Image Upload
- Browse Products
- Product Search
- Add to Cart
- Quantity Management
- Secure Checkout
- Razorpay Payment Integration
- Order History
- Invoice Download (PDF)
- Responsive Mobile-Friendly UI

---

## 🛠️ ADMIN FEATURES

- Admin Login
- Add Products
- Edit Products
- Delete Products
- Manage Inventory
- View Orders
- Dashboard Access

# ⚙️ INSTALLATION

## 1️⃣ CLONE REPOSITORY

```bash
git clone https://github.com/your-username/smartcart.git
cd smartcart
```

---

## 2️⃣ CREATE VIRTUAL ENVIRONMENT

```bash
python -m venv venv
```

Activate virtual environment:

### 🪟 WINDOWS

```bash
venv\Scripts\activate
```

### 🍎 LINUX / MAC

```bash
source venv/bin/activate
```

---

## 3️⃣ INSTALL REQUIREMENTS

```bash
pip install -r requirements.txt
```

---

## 4️⃣ INITIALIZE DATABASE

```bash
python init_db.py
```

---

## 5️⃣ RUN APPLICATION

```bash
python app.py
```
